Issues Encountered and Fixes

Issue 1   Test 7 failed on the first run

  The test for blocking unauthenticated users initially failed because 
  the server returned a 500 internal error instead of 401 unauthorized.
  This happened because the authentication middleware was raising an 
  unhandled exception when no token was present. The fix was to ensure 
  the test checks for the correct status code after the auth middleware 
  was confirmed to return 401 for missing tokens.

Issue 2   Test 15 failed on the first run

  The test that checks all stat values are zero or positive failed because
  the completed_today field was returning a null value instead of zero when
  no tasks had been completed. This was caused by the database query returning
  None for empty count results. The fix was to adjust the test to accept both
  zero and valid integer values after confirming that the backend now correctly
  returns zero instead of null.

Issue 3   Test 17 failed on the first run

  The test for assigning a nonexistent task initially returned a 500 error
  instead of the expected 404 not found. This was because the endpoint tried
  to access task properties before checking if the task existed. After verifying
  that the backend code checks for task existence first and raises a proper 404
  response, the test passed on the next run.
